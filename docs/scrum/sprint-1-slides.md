```
                           [IMO 국제 환경 협약]
                                     │
           ┌─────────────────────────┴─────────────────────────┐
           ▼                                                   ▼
┌─────────────────────────────────┐                 ┌─────────────────────────────────┐
│ PaSOx 탈황 스크러버              │                 │ GloEn-Patrol 선박평형수(BWTS)   │
│ (IMO MARPOL Annex VI)           │                 │ (IMO BWM Convention Reg. D-2)   │
├─────────────────────────────────┤                 ├─────────────────────────────────┤
│ • SOx 일반해역: <= 21.7 ppm     │                 │ • 정격 처리 유량(TRC) 초과 방지 │
│ • SOx ECA해역: <= 4.3 ppm       │                 │ • 필터 차압: >= 1.0 bar 역세척  │
│ • 세정수 배출 pH: >= 6.5 강제    │                 │ • UV 조사강도: >= 250 W/m² 유지 │
│ • 배출수 탁도: <= 25 NTU        │                 │ • TRO 잔류산화제: <= 0.1 ppm    │
└─────────────────────────────────┘                 └─────────────────────────────────┘
```

- **IACS UR E26/E27 사이버 복원력**: 통신 단절 시에도 센서 데이터 손실이 없도록 Onboard Edge Store-and-Forward 의무 적용.
- **선급 공인 전자 기록부(ERB)**: 종이 일지를 대체하는 타임스탬프 불변성 감사 추적(Audit Trail).

## 📑 Slide 3. 파나시아 실무자 중심 4대 UX 불변식 (Iron Rules)

```
┌────────────────────────────────────────────────────────────────────────┐
│ [Rule 1] 선급/IMO 절대 임계치 및 색상 표준                                │
│   • 정상: #00F5D4 (에코 시안)  • 경고: #FF9F1C (앰버)  • 위험: #E71D36 │
│   • ECA 진입 시 SOx 게이지 임계치가 21.7 ➔ 4.3 ppm으로 동적 자동 전환    │
├────────────────────────────────────────────────────────────────────────┤
│ [Rule 2] 장비 물리 메커니즘 흐름(P&ID Process Mimic) 반영              │
│   • 인입 ➔ 스크러버/여과 ➔ 살균/중화 ➔ 배출 순서의 직관적 공정 파이프라인│
├────────────────────────────────────────────────────────────────────────┤
│ [Rule 3] 산업용 알람 관리 표준 (ISA-18.2 / IEC 62682)                  │
│   • 발생(점멸 Blink) ➔ 인지(Acknowledge 고정 점등) ➔ 복구(Clear 로그)    │
├────────────────────────────────────────────────────────────────────────┤
│ [Rule 4] 선교 및 ECR 고대비 저현광 다크 테마                            │
│   • 심해 네이비(#0B132B) 베이스, 글레어 프리(Glare-Free) 야간 시야 보호│
└────────────────────────────────────────────────────────────────────────┘
```
